# cartoload

Convert official geodata into GPS device maps.

cartoload is an open-source CLI tool and Python library that converts geodata from any WMTS, WMS, GeoTIFF, or vector source into maps for GPS devices.

## Features

- Download maps from WMTS, XYZ/TMS, and STAC/GeoTIFF sources
- Export to Garmin raster `.img` format (more exporters coming soon)
- Source-agnostic — configure any WMTS or GeoTIFF provider
- Example configs for swisstopo, basemap.at, and IGN France
- Usable as CLI tool or Python library
